▸ Real-Time Chat System
GitHub Repo

A Facebook Messenger–style one-to-one chat application built from scratch. Focused entirely on the backend: real-time delivery, persistence, and concurrency correctness. React frontend is minimal — it exists only to exercise the API surface.

FastAPI PostgreSQL Redis python-socketio Celery SQLAlchemy (async) Alembic React
schema: users, conversations, messages; circular FK resolved with nullable last_message_id
realtime: two-room WebSocket pattern (user room + conversation room) for targeted event delivery
caching: Redis for fast data access + update ops; conversation list cached with TTL
pagination: cursor-based (keyset) pagination for message history — no OFFSET drift
concurrency: DB-level row guards prevent duplicate conversation creation under race conditions
celery: Celery for background task processing
